# UI/UX Design Guide - Aura

> Frontend design and implementation by **Manpreet**  
> Mental Health Companion Application

---

## Design Philosophy

### Core Principle
Create a **calming, accessible, and intuitive** interface that supports users during vulnerable mental health moments without overwhelming them with complexity.

### Design Goals
1. **Reduce cognitive load** - Simple, clear layouts
2. **Build trust** - Consistent, reliable interactions
3. **Ensure accessibility** - Inclusive design for all users
4. **Promote calmness** - Soothing colors and smooth animations

---

- **Purple (#9C27B0)** - Wisdom, spirituality, introspection
